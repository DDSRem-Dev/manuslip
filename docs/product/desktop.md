# Manuslip

<!-- impeccable:product-schema 1 -->

## Platform

web

Electron desktop application for Windows, macOS and Linux, built with React and CodeMirror.

## Product Purpose

Edit local Markdown documents and read translated copies without changing the source.

## Operating Context

Local documents, folder workspaces, multiple open tabs, keyboard commands, live editing,
source editing, translated reading, and document export. English and Simplified Chinese
interfaces. Inferred audience: people writing and reading long-form Markdown documents.

## Capabilities and Constraints

Preserve file handling, recovery, undo, input composition, conflicts, accessibility, translation
permissions, optional plugins, sync, and export. Translation runs only when requested.
Keep the existing Electron, React, Zustand, and CodeMirror architecture.

## Brand Commitments

The user requests a full UI/UX refactor guided by the supplied local Typora installation,
restrained elegance, concise copy, unified Phosphor icons, and purposeful animation.

## Product Principles

- Give the document priority over interface controls.
- Use familiar, discoverable desktop editing conventions.
- Keep secondary tasks out of the writing surface.
- Explain consequential choices and errors in plain language.
